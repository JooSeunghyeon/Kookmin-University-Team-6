### 포인트 장부 SQL 대조 (2,000P 의뢰)

| 거래 | 금액 | 확인 |
| --- | --- | --- |
| ESCROW_HOLD (의뢰자) | -2,000P | 통과 |
| PAYOUT (수행자) | +1,800P | 통과 |
| FEE (플랫폼) | -200P | 통과 |

에스크로 금액 = 수행자 입금 + 수수료로 정확히 일치. 긴급 옵션 수수료(URGENT_FEE)도 별도 기록 확인.

### 수수료 상한 검증

`_platform_fee(price)` = `least(floor(price * 0.1), 1000)`

| 2,000P | 200P | 1,800P |
| 10,000P | 1,000P | 9,000P |
| 20,000P | 1,000P (상한) | 19,000P |

## 발견·수정한 버그

### 1) "지원한 의뢰" 탭이 항상 비어 보임

`applications`와 `errands` 사이에 FK가 두 개(`applications.errand_id`, `errands.selected_application_id`) 있어
PostgREST가 관계를 특정하지 못하고 `PGRST201`을 반환했다. supabase-js는 이때 `data: null`을 주는데
호출부가 `data ?? []`로 처리해 **에러 없이 빈 목록**으로 보였다.

수정: 임베드에 FK를 명시 → `errands!applications_errand_id_fkey`.
커밋 `dd9d6b5`. 재배포 후 지원 6건 정상 표시 확인.

### 2) 모임 참여·댓글이 500 에러로 전부 실패

`fn_join_gathering` / `fn_add_gathering_comment`가 `notifications`에
`GATHERING_JOIN` / `GATHERING_COMMENT` 타입을 넣는데 `notifications_type_check` 제약에
두 값이 없어 insert가 막혔다.

수정: 마이그레이션 `0009_gathering_notification_types.sql`로 제약에 두 타입 추가. 커밋 `481730f`.

### 3) 온라인 의뢰 최소 금액 완화가 테이블 제약에 막힘

`fn_create_errand`만 500P로 완화했으나 `errands_price_check`가 여전히 `price >= 1000`이었다.

수정: 마이그레이션 `0011_errands_price_range.sql`로 `price between 500 and 100000`으로 변경.

## 지도 기능 제거

카카오맵 SDK가 `401 AccessDeniedError: domain mismatched`로 계속 차단됐다. 키 자체는 유효하지만
카카오 개발자 콘솔에 **어떤 도메인도 등록되지 않은 상태**(`campusrun-lime.vercel.app`, `localhost:3000` 모두 거부)였고,
콘솔 등록은 서비스 소유자만 할 수 있어 사용자 요청에 따라 지도 기능을 전면 제거했다.

제거 대상: `/map` 페이지, 클러스터 지도, 경로 지도, 위치 핀 지도, 카카오 SDK 로더·타입 정의.
하단 탭의 "지도"는 "채팅"으로 교체했다. 위치 입력은 캠퍼스 장소 선택 / 직접 입력(텍스트) / 온라인 세 가지로 유지된다.
